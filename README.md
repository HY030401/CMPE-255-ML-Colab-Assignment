# CMPE 255 - ML Colab Assignment

This repository contains six Google Colab notebooks covering K-Means clustering, AutoGluon, NVIDIA RAPIDS, and PyCaret.

Each notebook was executed in Google Colab with outputs and artifacts preserved.  
A video walkthrough is also provided for each part.

---

## Part 1 - K-Means From Scratch and Variations

Notebook: `Part1_KMeans/01_final_kmeans_zero_to_hero.ipynb`

Topics:

- Lloyd's K-Means algorithm from scratch
- Assignment and centroid update steps
- Convergence and SSE
- Random initialization
- K-Means++
- K-Means variations
- Choosing the number of clusters
- Customer segmentation
